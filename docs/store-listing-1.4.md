## Distribution setting (important)

Developer Dashboard > Distribution > Visibility: Public, but restrict **regions to Mexico** (plus United States if you want cross-border sellers). Most early installs were ChromeOS outside Mexico and never converted; they also drag the install/uninstall and rating signals.

## Privacy practices tab (must match the policy)

- Personally identifiable information: **Yes, email**, collected only by the payment processor (ExtensionPay) when the user pays. Not sold, not used for anything else. The 7-day trial is local and starts when the seller saves a first cost: no email, no card. A random payment ID is created only if the user opens checkout or logs in; subscription status is then checked when the user uses Mercado Libre pages or starts Chrome.
- Chrome sync: some preferences sync across the user's own Chrome profiles.
- Financial/payment information: handled by Stripe via ExtensionPay; Netio never sees card data.
- Website content / browsing: **No** (pages are read locally to compute fees; nothing is transmitted). The local price history of opened listings stays in the browser (listing pages only) and is deleted with "Borrar datos guardados".
- Wording rule: never claim that no data at all is collected; say "No recopilamos datos de navegación ni de ventas. Si contratas PRO, ExtensionPay procesa tu correo y pago."
